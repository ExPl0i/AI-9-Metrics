# Метрики качества

Занятие курса «Искусственный интеллект» для 9 класса. Ученики пишут с нуля свой `sklearn.metrics` и разбираются, что скрывается за `accuracy_score`, `precision_score`, `roc_auc_score` и `log_loss`.

## Содержимое

| Файл | Описание |
|---|---|
| `Метрики_качества.pptx` | Презентация к занятию (21 слайд) |
| `ПР-Метрики качества.ipynb` | Практическая работа (8 заданий + задания повышенной сложности) |

## Теория (презентация)

1. **Матрица ошибок** – четыре исхода, ловушка accuracy.
2. **Precision и recall** – цена ошибки, F-мера, порог классификации.
3. **ROC-AUC и функции потерь** – ROC-кривая, AUC как доля верно упорядоченных пар, log loss, несколько классов, метрики регрессии.
4. **Пишем метрики на Python** – план практики и шпаргалка по выбору метрики.

## Практическая работа

| Задание | Что пишем |
|---|---|
| Е1 | Матрица ошибок |
| Е2 | Accuracy, precision, recall, specificity |
| Е3 | F-мера |
| Е4 | Порог классификации |
| Е5 | ROC-кривая и AUC |
| Е6 | Функции потерь: log loss, Brier score |
| Е7 | Несколько классов: macro- и micro-усреднение |
| Е8 | Метрики регрессии: MAE, MSE, RMSE, R² |

Данные: учебный пример со спам-фильтром и датасеты scikit-learn – Breast Cancer, Wine, Diabetes.

Задания повышенной сложности: balanced accuracy и G-среднее, поиск лучшего порога по F1, AUC через пары.

**Правило работы:** внутри своих функций – только списки, словари, циклы, `sum`, `len`, `zip` и `math`. `sklearn` используется только в готовых ячейках. После каждого задания есть ячейка «Проверка»: если все строки начинаются с `OK`, можно идти дальше.

## Требования

Python 3.8+, `scikit-learn`, `matplotlib`.
